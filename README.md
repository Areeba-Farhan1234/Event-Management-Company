# Event Management Company Website

A professional website for an **Event Management Company** to showcase events, services, gallery, testimonials, and booking form.

## Features

- Responsive design using **Bootstrap 5**  
- Sections: Home, Events, Services, Testimonials, Gallery, Booking  
- Upcoming and past events showcase  
- Booking form for clients  
- Image gallery carousel and testimonial slider  

## Project Structure

Event-Management-Company/
├─ index.html
├─ style.css
├─ img/ # Event, gallery, and testimonial images
├─ js/

## Deployment

- Static website hosted on GitHub Pages or any static server.  
- Simply upload HTML, CSS, and images to the server to deploy.
